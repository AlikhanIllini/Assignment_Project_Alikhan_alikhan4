📈 Data Flow
  1. API Request: View builds absolute URL using build_absolute_uri(reverse(...))
  2. Fetch JSON: Server fetches data with urllib.request.urlopen()
  3. Parse Data: JSON parsed with json.load()
  4. Generate Chart: Matplotlib creates visualization
  5. Return PNG: HttpResponse(..., content_type="image/png")
