IP9: APIs + JSON Endpoints + Server-Side Charts

Task Board Application - Django Kanban System

Project Recap

A Django task management app with projects, tasks, and visualization features.

JSON API Endpoints Exposed

1. All Tasks API

/tasks/api/tasks/

Returns complete list of all tasks with details (title, description, status, priority, due dates)

2. Task Statistics API

/tasks/api/stats/

Returns aggregated statistics (overall stats, status/priority/project breakdowns)

3. Server-Side Chart PNG

/tasks/api/chart.png

Returns image/png generated from API data using matplotlib

Server-Side Chart View (Core Flow)

Data → Chart Flow (No JavaScript!)

def task_chart_png(request):
    # 1. Build absolute API URL
    api_path = reverse('task_stats_api')
    api_url = request.build_absolute_uri(api_path)

    # 2. Fetch JSON from API (server-side)
    with urllib.request.urlopen(api_url) as response:
        data = json.load(response)

    # 3. Extract data from JSON
    status_data = data['status_breakdown']
    priority_data = data['priority_breakdown']
    overall_stats = data['overall']

    # 4. Generate matplotlib chart
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))
    # ... create pie charts, bar charts, stats display ...

    # 5. Save to buffer and return as image/png
    buffer = io.BytesIO()
    plt.savefig(buffer, format='png', dpi=100)
    plt.close(fig)
    buffer.seek(0)

    return HttpResponse(buffer.getvalue(),
                       content_type='image/png')

Key Functions:

  • reverse() - Get URL pattern by name
  • build_absolute_uri() - Convert to full URL with domain
  • urllib.request.urlopen() - Fetch HTTP response
  • json.load() - Parse JSON from response
  • HttpResponse(..., content_type='image/png') - Return PNG bytes

HttpResponse vs JsonResponse

MIME Type & Use Case Comparison

Aspect HttpResponse JsonResponse
Default MIME Type text/html application/json
Custom Content Type Set manually: content_type='image/png' Always JSON
Serialization Manual (convert to string/bytes) Automatic JSON encoding
Use Case HTML pages, images, PDFs, custom content API endpoints returning JSON

When to Use Each (In This Project)

JsonResponse - API Endpoints

return JsonResponse({
    'overall': {...},
    'status_breakdown': [...]
})

✅ Automatically serializes dict → JSON
✅ Sets Content-Type: application/json

HttpResponse - Image/Custom

# For PNG chart:
return HttpResponse(
    png_bytes,
    content_type='image/png'
)

✅ Custom content type control
✅ Binary data support

Decision: JsonResponse for APIs (correct MIME type + auto serialization), HttpResponse for images with explicit content_type.
