# Ideas & Selection Rationale
- Assignment ideas: Stock Cards Lite
- Final ideas: Stock Cards — Ultimate
- Selected: Stock Cards Lite (Assignment), Stock Cards — Ultimate (Final)
- Why: same domain, scoped growth; minimal re-learning

# Wireframe Notes
- Goal of v1 wireframes: Keep it tiny and shippable. Prioritize cards + simple filters over charts/analytics.
- Screens included:
    - login (ultimate edition only)
    - dashboard: card grid (ticker, target, conviction 1-5, horizon 1-5, one-line note) + filters.
    - create/edit card: tight form; "last price" field (API)
    - empty/error: first-run blank state, basic validation and network error copy.

# Branching Strategy
- Strategy chosen: Simple Gitflow
    - main (protected, demo-ready)
    - develop (integration)
    - feature/ per weekly topic -> merge back to develop
    - release/ before demos -> merge to main
    - hotfix/ from main for urgent fixes -> merge back to develop

- Planned feature branches (Lite):
    - feature/models -> feature/crud -> feature/ui -> feature/reporting -> feature/api

# Django Setup
- startproject folder name chosen: appserver; app name: cards — simple and clear.

# Virtual Environment Choice
- Using Python venv because it's simple and works with PyCharm auto-detect.
